# 3D 目标环境文档

3D（`three-d`）的被测目标是三维应用与编辑工具的运行时实例，代表工具是 Blender。跨环境定义及配置索引见[目标环境定义与配置入口](../target-environments.md)。

本环境当前为 planned：可在设置页启用、可切换空白视图，尚未接入适配器。下面的文档说明**如何把 Blender 运行时准备成可被检测和操作的状态**，这是接入适配器的前置条件；它不承诺已经存在 `three_d_*` 工具。

| 插件安装 | [快速开始](../getting-started.md) |

## 宿主平台与执行端

| 项目 | 当前状态 |
| --- | --- |
| 宿主平台 | Linux 已实测；Windows、macOS 已给出安装与验证路径，尚未实测 |
| 执行端 | Blender 官方发布版（便携归档） |
| 目标类型 | Blender 实例（GUI 会话或无头进程） |
| 适配器 | 未接入 |
| 工具 | 未注册 |

宿主平台差异只体现在安装形态和显卡路径上，判断一个实例能否被有效使用的方法是同一套：先确认版本，再确认渲染器身份，最后跑一次真实出图。详见[运行时安装与配置](blender-runtime.md#验证)。
