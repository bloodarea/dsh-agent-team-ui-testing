# 3D 目标环境文档

3D（`three-d`）用于观察三维应用与编辑工具的场景。调试视图已支持 Blender 纯视口。Agent 执行适配器仍在规划中。

| 主题 | 文档 |
| --- | --- |
| 调试视图与交互 | [Blender 纯视口](debug-panel.md) |
| 运行时安装与 GPU 配置 | [Blender 运行时配置](blender-runtime.md) |
| 插件安装 | [快速开始](../getting-started.md) |
| 环境定义与配置 | [目标环境定义与配置入口](../target-environments.md) |

Blender 纯视口需要 Linux Host、Blender 和 Xvfb。Windows 与 macOS 的 Blender 安装方法见运行时配置文档。
