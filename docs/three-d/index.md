# 3D 目标环境文档

3D（`three-d`）用于观察三维应用与编辑工具的场景。Blender 面板支持从 DSH 工作区加载和重载工程、九个 Blender 工作区、布局时间轴、原生大纲和属性浮窗、视口显示设置、原生偏好设置和实例内参考图库，以及鼠标选择、原生菜单、旋转、平移和缩放。Agent 执行适配器仍在规划中。

| 运行时安装与 GPU 配置 | [Blender 运行时配置](blender-runtime.md) |
| 插件安装 | [快速开始](../getting-started.md) |
| 环境定义与配置 | [目标环境定义与配置入口](../target-environments.md) |

Blender 纯视口支持 Linux 和 Windows Host。Linux 使用 Xvfb，Windows 使用独立的 Win32 桌面。
