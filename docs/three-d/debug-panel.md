# Blender 纯视口

Linux 和 Windows 上可以在调试视图中打开 Blender 的 3D 视口。进入 **设置 → UI 测试**，启用「3D 视图」分组，确认「Blender」卡片的开关处于启用状态，然后在 **更多 → 调试视图** 或右侧的调试面板切换到「3D 视图」。在画面里用左键选择对象，右键打开 Blender 原生菜单，中键拖动旋转视角，Shift + 中键拖动平移，滚轮缩放。按 Esc 可关闭菜单或取消 Blender 当前操作。进入标注时，鼠标用于面板标注。

- 工具栏中的「工作区切换」按钮位于视口着色左侧，单击展开或收起工作区标签。选择标签后，面板切换到同一 Blender 实例里的对应工作区。初始工作区为「布局」。
- 视口着色图标表示当前主 3D 视图的模式，单击按「线框 → 实体 → 材质预览 → 渲染」循环。布局初始为实体，材质预览和渲染切换后补一次画面更新。渲染与合成工作区没有 3D 视图，此时着色按钮不可用。
- 底部状态栏按顺序显示实际图像分辨率、最近一帧从请求到加载的耗时和最近一秒显示的帧数（FPS）。Blender 按需出帧，画面停止更新后显示 `0 FPS`。首次出图后，右下角在操作和刷新期间持续显示「Blender · 可操作」。
- 「尺寸调整」提供三个横屏画质档位。性能（960×540，默认）使用窗口原始尺寸，高清（1280×720）和极致（1920×1080）使用放大后的输出。
- 尺寸栏也支持手动宽高、适应窗口与显示缩放。输出宽高单边为 200–4096 像素，总面积上限为 8,388,608 像素。适应窗口和显示缩放只改变面板中的呈现比例。
- 标注使用公共绘图工具，保存在当前面板的 3D 画布中，与 Web 标注分开。截图将已提交的图形与当前 Blender 帧合成为 PNG，可加入当前会话的聊天框。

## 工程选择和重载

工具栏左侧显示当前工程。未选择工作区文件时显示「默认场景」。点击框内的下拉按钮可列出当前面板所绑定的 DSH 工作区中的 `.blend` 文件，包括子目录。列表使用相对路径；输入名称可筛选，选择列表项后加载该工程的场景数据，调试面板沿用自己的纯视口布局。点击「默认场景」可返回启动场景。

编辑框右侧的「重载 Blender」会重启当前调试实例并重新读取同一个工程。重载会放弃临时实例中未保存的场景更改，并重新读取 DSH 中已保存的 Blender 偏好。工程扫描跳过隐藏目录、依赖目录和符号链接。

## 显示设置

点击「大纲视图」左侧的「显示设置」，可在下一行打开「可选择性&可见性」「视图操控器」「视图叠加层」和「视图着色方式」。每项在按钮下方打开独立浮窗，显示当前主 3D 视口的 Blender 原生设置。拖动标题栏移动，点击右上角 × 关闭。收起设置行时，已打开的浮窗会保留。

要显示摄影机和灯光的辅助图形，在「视图叠加层」的「物体（Objects）」中开启「附加项（Extras）」。渲染和合成工作区没有主 3D 视口，因此这些设置会暂停，切回有 3D 视口的工作区后继续可用。

## 大纲视图和属性编辑器

在「工作区切换」左侧点击「大纲视图」或「属性编辑器」，可打开对应的 Blender 原生编辑器。「大纲视图」浮窗从自己的按钮下方打开，两块浮窗可以同时显示。拖动标题栏移动，点击右上角 × 关闭。再次点击工具栏按钮会将已打开的浮窗置顶。

浮窗与主画布共用同一场景和视图层。在大纲中选择对象时，主视口和属性编辑器会同步。属性编辑器支持切换类别、点击和滚动。Esc 可退出原生菜单，浮窗仍保持打开。

## Blender 设置

点击「尺寸调整」右侧的 **更多 → Blender设置**，在菜单项下方打开 Blender 的原生「编辑 → 偏好设置」窗口。首次打开显示「插件（Add-ons）」页，可以用鼠标切换左侧分类、点选控件和滚动。拖动标题栏移动浮窗，点击右上角 × 关闭。再次打开已显示的浮窗会将它置顶。渲染和合成工作区也可打开偏好设置。

点击原生「保存偏好设置」后，Blender 将偏好写入 DSH 配置目录，默认文件为 `${DSH_HOME}/ui-testing/blender/userpref.blend`。若设置了 `DSH_UI_TESTING_CONFIG_DIR`，则保存到该目录下的 `blender/userpref.blend`。新的 Blender 调试实例启动时自动读取此文件。调试视口沿用自己的启动画面、工程保存提示、临时目录和工程自动保存规则。桌面版 Blender 仍使用自己的配置。

## 参考图设置

点击 **更多 → 参考图设置**，在菜单项下方打开浮层。点击右上角 × 关闭。将图片拖到列表底部的虚线框，或点击虚线框打开文件选择器，支持一次选择多张图。以松手位置为准，虚线框内添加到参考图列表，框外由 DSH 处理对话附件。

列表按添加顺序显示「参考图-1」「参考图-2」等。新条目默认折叠，点击条目可查看完整图片。点击条目右侧的 × 可移除该参考图，剩余条目按原顺序从 1 重新编号。桌面端在名称下方显示原始文件路径，浏览器只提供文件名时显示文件名。支持 PNG、JPEG、WebP、GIF、BMP 和 AVIF，每张最多 32 MiB，每个实例最多 64 张、合计 128 MiB。

参考图以当前 Blender 实例为作用域，同一 DSH 工作区的会话共享列表。关闭浮层或调试视图后可重新打开列表。重载、切换工程或实例关闭后，列表和图片数据随实例清除。参考图可在浮层中查看，图片数据保留在内存中。

## 工作区布局

各工作区的主画面显示对应的编辑器画布，隐藏原生标题栏、工具栏、侧栏和资产架。工作区通过调试面板工具栏切换。

选中「布局」时，原生时间轴内嵌在调试面板底部，固定在分辨率、延迟和 FPS 所在的状态栏正上方。主画布滚动或缩放时，时间轴仍在该位置。点击或拖动帧刻度可改变同一场景的当前帧，也可用原生按钮播放和暂停。切换到其他工作区时，面板收起这条时间轴。

| 工作区 | 主画面编辑器布局 |
| --- | --- |
| 布局、建模、雕刻 | 单页 3D 视图 |
| 渲染 | 单页渲染结果，显示 Blender 已有的渲染图 |
| UV 编辑 | 左侧 UV 编辑器，右侧 3D 视图，各占一半宽度 |
| 纹理绘制 | 左侧图像绘制，右侧 3D 纹理绘制，各占一半宽度 |
| 着色 / 材质 | 上方材质预览，下方着色器节点，两行各占全宽 |
| 动画 | 上方左侧相机、右侧 3D 视图，底部是通栏动画表 |
| 合成 | 上方图像预览，下方合成节点，两行各占全宽 |

## 启用条件

取画面要同时满足两个开关，缺一个都返回 `409 ADAPTER_DISABLED`，面板直接把原因显示在视口上：

| 开关 | 配置字段 | 关闭时的提示 |
| --- | --- | --- |
| 3D 视图总开关 | `environments.three-d.enabled` | 请先在设置中启用 3D 视图。 |
| Blender 运行环境 | `environments.three-d.providers.blender.enabled` | 请先在设置中启用 Blender 运行环境。 |

Blender 是 3D 视图的**运行环境**（provider），工程支持度为 `supported`：它同时提供视口画面与 Agent 执行适配器。第一次读取配置时 Blender 默认为开启，所以只打开 3D 总开关就能看画面；把它单独关掉不会停用整个 3D 分组，但会让 `blender_*` 工具退出准入。开关语义见[运行环境（provider）开关](../target-environments.md#运行环境provider开关)。

配置保存在 `${DSH_HOME}/ui-testing/config.json`，改动立即生效，不需要重启 DSH。

## Host 依赖

- 在运行 DSH 的主机上安装 Blender。Linux 另外需要 Xvfb，Windows 使用系统自带的 Windows PowerShell。安装方式和发现规则见[运行时配置](blender-runtime.md)。
- 可通过 `DSH_UI_TESTING_BLENDER` 指定可执行文件的绝对路径。Linux 可用 `DSH_UI_TESTING_XVFB` 指定 Xvfb。
- 「默认场景」通常加载 Blender 出厂场景。Host 可用 `DSH_UI_TESTING_BLEND_FILE` 指定一个可信的绝对 `.blend` 路径作为启动场景。Blender 禁用工程脚本自动运行。选择与菜单操作在临时运行实例中执行，面板关闭时不会保存工程。
- 修改 Host 的启动环境后，须重启 DSH 并刷新网页；只改设置页开关不需要重启。

## 视口行为

Host 按需在隔离的显示环境里启动 Blender，Linux 使用私有 Xvfb 显示，Windows 使用独立的 Win32 桌面。当前 Windows 桌面不会显示 Blender 的原生窗口或切走焦点。面板把鼠标事件发给 Blender，并接收包含选择高亮和弹出菜单的原生画面。主画面等比放进所选输出尺寸，标注截图使用主画面的分辨率。Linux 默认使用 Mesa 软件 OpenGL 渲染。连续移动事件会合并，按下和释放会按顺序送达。

同一 DSH 工作区内的会话共享一个 Blender 实例，包括已打开的工程和未保存的场景改动。不同 DSH 工作区各有自己的实例。关闭面板、切换会话或长时间空闲时，实例继续运行。选择工程或重载会重启当前工作区的实例，并影响该工作区内的其他会话。未绑定会话的面板可使用独立预览实例。

- 删除 DSH 工作区会关闭对应的 Blender 实例。会话必须关联到有效的工作区才可继续请求视口。
- 关闭设置中的 3D 总开关或 Blender 运行环境开关，会关闭所有 Blender 调试实例，包括独立预览实例。重新启用后，收到下一次有效的视口请求时才会启动新实例。
- 插件卸载或 Host 退出时也会释放全部实例。关闭实例会丢弃未保存的场景改动。

鼠标输入会送到画面中对应的 Blender 编辑器，面板也支持 Esc。原生菜单中的部分命令会修改临时 Blender 场景。其他键盘快捷键、额外的 Blender 系统对话框和 Agent 执行工具尚未接入。

## 验证

进入 3D 视图后，默认场景应出现立方体、网格和坐标轴。拖动后查看立方体的可见面是否变化，滚动后查看它的投影大小是否变化。Windows 上可在首次出图和操作期间检查当前桌面、任务栏与 Alt-Tab，并确认焦点留在正在使用的应用。返回 Web 视图后核对原来的页面。依赖缺失、Host 未响应或渲染失败时，面板会显示错误并提供重试入口。
