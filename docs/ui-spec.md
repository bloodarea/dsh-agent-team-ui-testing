# 已定稿界面规格

> 索引：[docs/index.md](index.md) · **改动需用户同意**（见 [status.md](status.md) 的冻结约定）

1. **顶部环境栏**（44px）：圆角窗口图标 + 单行标题 `Web · 调试视图`（垂直居中，无副标题）+ 右侧运行环境 `select`（9 项，仅 `Web 视图` 可选，其余 `disabled`）。
2. **工具栏**（41px）：后退 / 前进 / 刷新 / 地址栏 / **标注** / 尺寸调整 / 选择元素（禁用）/ 更多。图标 16×16、`strokeWidth 1.7`、`currentColor`；标注入口用画笔图案，选择元素用 Chrome「检查元素」样式（虚线框 + 指针）。**行为约定（2026-10-31，视觉规格不变）**：地址栏回显运行时主框架真实地址（含 query/hash），用户聚焦编辑期间不被轮询覆盖、Esc/blur 取消草稿；刷新/后退/前进由浏览器真实 CDP 历史驱动，按钮禁用取真实 `canGoBack/canGoForward` 与运行时状态；旧 Host（未重启）降级为显示脱敏 URL 且三个导航按钮禁用。**双向模式互斥（2026-11-03 第 2 条）**：尺寸调整开启时「标注」入口原生 `disabled`（`data-utb-annot-entry=sizing`、`title=尺寸调整模式下不可进入标注（先关闭尺寸调整）`，程序化进入 `enterAnnotMode` 同一道闸），关闭尺寸栏后恢复 `ready`；反向“标注模式内尺寸入口禁用”保持不变。
3. **标注栏**（开启标注模式时出现在工具栏下方、尺寸栏之前）：左侧七个单选工具 `圆形 / 矩形 / 线段 / 箭头 / 画笔 / 文字 / 橡皮擦`（单选高亮，图标 16×16、`strokeWidth 1.7`）+ **`填充 | 外框` 分页选择器**（`div.utb-seg[role=group][aria-label=填充与外框][data-utb-annot-seg=fill-stroke]`，两个 `button[data-utb-annot-mode=fill|stroke][aria-pressed]`，样式同预设按钮的品牌色高亮；**恰好一项选中、默认「外框」、点已选项完全 no-op**；**选中项左侧显示 8×8 SVG 绿色小圆点**（`#22c55e`、`<circle r="3">`、`aria-hidden`，未选中项同位置保留 8px 占位并 `visibility:hidden`，切换时文字不位移），提供 `data-utb-seg-dot=on|off` 与 `data-utb-seg-group=fill-stroke` 钩子；仅圆形/矩形可改，line/arrow/brush/text/eraser 下整组 `disabled` 但保留所选；实现改为单一真源 `fill`/`stroke` 二选一，GUI 不再产出“同时填充+描边”，旧标注数据仍可读/可擦，Host 的 `fill`/`stroke` 布尔契约不变）+ 颜色（原生色盘，默认 `#ff3b30`）+ 粗细（数字输入 1–20，默认 3；**支持鼠标滚轮：±1、Shift ±5、Alt ±1（Alt 优先），clamp 1–20，滚轮被吞掉不滚页面，文字/橡皮擦工具下不响应**；文字工具时禁用；橡皮擦下颜色/粗细一并禁用但保留值）+ 最右侧 `清除画布` 文案按钮（`aria-label`/`title=清除画布`、`data-utb-annot-action=clear`；无二次确认；无已完成/草稿/编辑时禁用；按下先取消文字编辑以防 blur 复活）。**打开标注栏 = 进入标注模式（用户 2026-11-02 要求）**：模式内只允许标注子功能，页面零交互（点击/拖拽/滚轮/键盘都不派发；预览区滚轮被面板吞掉）；地址栏/后退/前进/刷新/更多/环境选择/尺寸调整入口禁用，尺寸栏不能在模式内打开，拖拽模式自动取消。标注以**画布 CSS px** 锚定在预览上（画布原点 C 变化时随内容移动、随显示比例缩放），空白区也可绘制。退出模式后标注继续显示但不可交互（穿透），页面交互恢复，拖拽保持关闭；关闭再打开保留工具/样式/已完成标注。**橡皮擦**按下即擦、拖动连续擦（hover 不擦，每次只删最上层一个对象，`r=max(线宽/2,6)` 画布 px 命中）。**同步状态**：标注层带 `data-utb-annot-sync`/`data-utb-annot-revision`，状态栏以 `aria-live=polite` 提示“标注未同步”（不弹窗、不写页面错误）——Agent 通过 Host 的 `browser_state.annotations`/`ui.annotations` 读取标注（v2，工具面仍 30）。**v3（2026-11-02 第三轮）**：标注**按工作区保留**——切页签/隐藏/卸载重挂/同工作区换会话都保留，切到别的会话但同一工作区看到同一份、换工作区只看到各自的一份；入口/状态 title 说明“标注按工作区保留，导航/刷新会清除当前页面标注”（不加弹窗或控件）。控件 aria-label、data-*、几何映射与 V15/V16/V17/V18 验收见 [annotation-p0d.md](annotation-p0d.md)。
4. **尺寸栏**（开启尺寸调整时出现）：左侧预设是分页选择器 `div.utb-seg[data-utb-preset][role=group][aria-label=分辨率预设]`，四项 `宽屏 1920×1080 / 横屏 1024×768 / 平板 768×1024 / 手机 393×852`（`button.utb-seg-btn.utb-preset[data-utb-preset-opt=wide|landscape|tablet|phone]`；**选中项左侧 8×8 绿色小圆点**，未选中项保留占位并 `visibility:hidden`；**选中态 = 非拖拽且最终宽高精确匹配，零或一项；拖拽模式下四项全部取消选中（互斥）**）；右侧 `X  Y  宽 × 高 px [拖拽 | 适应窗口] 缩放%` 全部右对齐，**分页选择器紧贴百分比输入**（组与 `%` 之间沿用 `gap`，≤6px）。**X/Y 是带符号的画布坐标（视口左上角在文档画布上的位置），可为负、可超出内容右/下边界；负值/越界时视口内露出纯白空白，内容随之反向移动。** **四个预设按钮（2026-11-03 用户报 bug 后修正）**：点任一预设 = 切到固定分辨率视图——宽高设为该预设，**X/Y 归零**（画布 Host 写 `canvasX/canvasY`，旧 Host 写文档滚动 `x/y`；目标页面滚动回到 0,0），并把右侧 `拖拽 | 适应窗口 | 默认` 分页选择器**只退出「拖拽」**：从「拖拽」点预设后回到「默认」（`pan=false, fit=false`）；原本是「适应窗口」则**保持适应窗口**（`fit` 仍为本地显示偏好，不发布比例）；原本是「默认」则保持默认；恰好一个 `aria-pressed`；**不改 `scale`/`%`**（共享 `view.scale` 不变；fit 开启时 `%` 仍显示本地适应比例，未开启时显示共享比例）。宽高与坐标合并成同一 120ms v1 patch（一次 `/viewport`，带 `expectedRevision`，不含 `scale`；旧 Host 无共享 view 时只写宽高）。
   - **`拖拽 | 适应窗口 | 默认` 分页选择器（2026-11-03 第 4 条 + 追加第 6 条）**：`div.utb-seg[role=group][aria-label=拖拽与适应][data-utb-panfit][data-utb-panfit-state=pan|fit|default]`，**顺序固定「拖拽」「适应窗口」「默认」**（前两项为用户指定顺序，默认追加在末尾），三个 `button[aria-label=拖拽视口|适应窗口|默认][aria-pressed]`；**任何时刻恰好一个 `aria-pressed=true`**，**选中项左侧显示同一个 8×8 绿色小圆点**（未选中项保留占位、`visibility:hidden`；`data-utb-seg-dot` / `data-utb-seg-group=panfit`）。
     - 选「拖拽」→ 关 fit + 开拖拽；选「适应窗口」→ 退拖拽 + 开 fit；选「默认」→ **既不是拖拽也不是适应窗口**（`pan=false, fit=false`），`%` 回到共享 `view.scale`，**点它本身不发布任何 `/viewport`**（纯本地显示策略）。
     - 点已选中项：「拖拽」→ 退出到「默认」；「适应窗口」→ 取消 fit 回落到「默认」且不发布；「默认」→ no-op。
     - **手动改百分比 / 拖拽模式滚轮缩放 → 自动选中「默认」**（不再有“两项都未选中”的空态），且**不会**因此打开拖拽。
     - 启用态：`拖拽` 需 `viewSync && canvasOn && !annotOn`（旧 Host/无画布时 `disabled`）；`适应窗口`/`默认` 仅标注模式内禁用。
   - **默认分辨率按运行环境确定（2026-11-03 第 3 条）**：`ENV_DEFAULTS` = web / windows / linux / macOS / TUI → **横屏 1024×768 + 适应窗口**，android / HarmonyOS → **手机 393×852 + 适应窗口**，游戏 / 3D → 宽屏 1920×1080；面板初值取当前环境默认（当前环境初始为 Web）。冷启动且 Host view 为 `source=default` 时按该默认**发布一次**（与 Host 现值完全相等则不发）；回访（已接受的非 default view）**不覆盖**；用户主动切换运行环境时套用该环境默认并只发布 `width/height`（不发布 `scale`）、`fit=true`、退出拖拽。当前仅 Web 视图可选，其余环境只写表不生效。
   - **数值输入共 5 个**（X/Y/宽/高/比例），`aria-label` 分别为 `视口 X 坐标（像素）`、`视口 Y 坐标（像素）`、`视口宽度（像素）`、`视口高度（像素）`、`预览缩放比例（百分比）`。X/Y 显示 Host 的 `canvasX/canvasY`（文档画布上的视口原点，带符号 CSS px，范围 ±10,000,000），**不是**页面滚动 `x/y`；标题文案说明可为负/内容外为空白。
   - **滚轮（用户 2026-11-01 要求）**：五个输入框均支持鼠标滚轮，向上增、向下减，`deltaY=0` 不改；X/Y/宽/高步长 10 CSS px（Shift=100、Alt=1），比例 5 个百分点（Shift=10、Alt=1），**Alt 优先于 Shift**；Ctrl/Meta+滚轮被面板吞掉（不编辑字段，也不触发 number 原生步进）。滚轮在 120ms 内合并成一个请求，宿主页面滚动与目标页都收不到该滚轮。
   - **比例语义**：`缩放%` 是**共享显示比例** `view.scale`（Host 权威，0.1–2 即 10–200%，也是"省略 scale 的截图默认密度"），不是 DPR、不是页面 zoom，不改变页面 CSS 视口与布局。手动改比例会取消「适应窗口」并把比例提交给 Host；`view.scale` 变化后 Agent 的默认截图尺寸也随之变化。
   - **画布空白（2026-11-02 用户要求）**：视口盒里内容盒之外的区域画**深色棋盘格**（14px 方格、`#2b2b2b`/`#3f3f3f`，固定屏幕像素、不随比例缩放；像 PS 的画布底色），不绘制页面内容——纯白页面 + 纯白空白时靠它分辨边界；点击/拖拽/滚轮落在空白上零派发。截图/T3 的 blank 仍是纯白 `#ffffff`（证据语义，不掺 UI 花纹）。`O=0` 时保持旧行为（不做空白 gating）；实时帧/合成 seed 与滚动证据不一致时输入 fail-closed（无 250ms 放行），静态页用 `/screenshot {canvas:true}` 的合成 seed 恢复。
    - **「适应窗口」只是本地显示偏好**：勾选时不向 Host 发布任何比例，输入框显示本地计算值（淡色/提示文案说明"仅本地显示"）；取消勾选只回到显示 Host 比例，不发布。收到 Agent 或另一面板的内容变更时采纳 Host 全部值并自动取消本地适应。
    - **「拖拽」视口（用户 2026-11-02 要求）**：`适应窗口` 与缩放百分比之间新增 `☑拖拽`（`aria-label="拖拽视口"`，无共享 `ui.view` 的旧 Host 时禁用）。勾选后鼠标在预览画面上变为抓取手势（按住时 `grabbing`），按住拖动按**内容跟手**方向平移**画布原点 canvasX/Y**（向右/下拖 → X/Y 减小，向左/上拖 → 增大；可进入负值/露白，范围 ±10,000,000）；空白区也可起手拖动（拖拽模式下有透明 overlay）。X/Y 输入框随 Host 画布坐标回显更新。移动期间的写入走与输入框相同的 `/viewport` v1/CAS 路径，但按 80ms 合并且同一时刻最多一个请求在途。勾选期间不向目标页面派发点击/拖拽/悬停；**画面滚轮改为缩放画布**（用户 2026-11-02 要求）：写共享 `view.scale`（步进 5%，Shift 10%，Alt 1%，范围 0.1–2），以**屏幕光标为锚点**（光标下的画布点在屏幕上不动，含盒子居中补偿：`d = C + (S−R.left)/s`、`C' = d − (S−left')/s'`），若「适应窗口」处于勾选态则**自动取消勾选**；Ctrl/Meta+滚轮不缩放。取消勾选、关闭尺寸栏或切换工作区都会解除拖拽并恢复默认光标与页面交互。
   - **窄面板**：尺寸栏与左右分组 `flex-wrap`，空间不足时换行，不覆盖预览区、不出现横向溢出（用户要求）。
   - 宽高范围 200–4096、X/Y 0–10,000,000；非法中间态不提交，Enter/blur 提交、Escape 恢复已接受值。
5. **底部状态栏**（26px）：左 `空闲 / 人类接管 / Agent 操作中` + 分隔线 + `N FPS  M ms`；右侧当前活动文案。FPS/延迟取自宿主页面 rAF，是真实测量值（不是目标页帧率）。
6. **入口**：左侧「更多」下拉里的一行「调试视图」→ 打开中间面板；右侧边栏「开始」页的卡片 → 打开右栏页签。
7. **预览区坐标映射**（行为约定，视觉不变）：帧按 `object-fit: contain` 居中显示，指针/滚轮/拖拽坐标按**实际绘制矩形**（解码后的 naturalWidth/Height + 容器内容盒）换算到页面 CSS 坐标，**不乘宿主 DPR**；letterbox 之外的点击不派发；拖拽在图外结束后仍补发释放，避免按键滞留。画面滚轮按 `W/Pw` 缩放后派发。**勾选「拖拽」时，同一绘制矩形用于把拖动位移换算成页面滚动位移**（`Δscroll = ΔhostPx × W / Pw`），不向页面派发鼠标事件。**标注模式下，同一绘制矩形用于把指针位置换算成画布 CSS px**（`d = C + (client − P.left) / (P.width/W)`，不乘 DPR、不叠加 O）。
8. **没有提示条**：错误通过地址栏红框 + 空状态文案 + 视觉隐藏的 `role="alert"` 表达。

> 第 4 项中的 X/Y 输入框、五个数值框滚轮、fit 本地语义、窄面板 wrap 与 **`☑拖拽` 视口模式**，以及第 2/3 项中的**标注入口与标注栏**，都是**用户明确要求的界面变更**（2026-11-01 / 2026-11-02）；其余样式/文案/图标/间距/颜色/布局仍按冻结约定处理，改动需再次获得用户同意。行为契约见 [viewport-control.md](viewport-control.md) §4–§5 与 [annotation-p0d.md](annotation-p0d.md)，GUI 证据见 [status.md](status.md) 与 `viewport-gui.mjs` 的 V12–V15。
