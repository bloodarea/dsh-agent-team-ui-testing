# 已定稿界面规格

> 索引：[docs/index.md](index.md) · **改动需用户同意**（见 [status.md](status.md) 的冻结约定）

1. **顶部环境栏**（44px）：圆角窗口图标 + 单行标题 `Web · 调试视图`（垂直居中，无副标题）+ 右侧运行环境 `select`（9 项，仅 `Web 视图` 可选，其余 `disabled`）。
2. **工具栏**（41px）：后退 / 前进 / 刷新 / 地址栏 / 尺寸调整 / 选择元素（禁用）/ 更多。图标 16×16、`strokeWidth 1.7`、`currentColor`；选择元素用 Chrome「检查元素」样式（虚线框 + 指针）。**行为约定（2026-10-31，视觉规格不变）**：地址栏回显运行时主框架真实地址（含 query/hash），用户聚焦编辑期间不被轮询覆盖、Esc/blur 取消草稿；刷新/后退/前进由浏览器真实 CDP 历史驱动，按钮禁用取真实 `canGoBack/canGoForward` 与运行时状态；旧 Host（未重启）降级为显示脱敏 URL 且三个导航按钮禁用。
3. **尺寸栏**（开启尺寸调整时出现）：左侧预设 `宽屏 1920×1080`、`横屏 1024×768`、`平板 768×1024`、`手机 393×852`（当前档位高亮，按最终宽高精确匹配）；右侧 `X  Y  宽 × 高 px ☑适应窗口 缩放%` 全部右对齐。
   - **数值输入共 5 个**（X/Y/宽/高/比例），`aria-label` 分别为 `视口 X 坐标（像素）`、`视口 Y 坐标（像素）`、`视口宽度（像素）`、`视口高度（像素）`、`预览缩放比例（百分比）`。X/Y 显示 Host 实测的页面顶层滚动位置（文档 CSS px），不是窗口位置。
   - **滚轮（用户 2026-11-01 要求）**：五个输入框均支持鼠标滚轮，向上增、向下减，`deltaY=0` 不改；X/Y/宽/高步长 10 CSS px（Shift=100、Alt=1），比例 5 个百分点（Shift=10、Alt=1），**Alt 优先于 Shift**；Ctrl/Meta+滚轮被面板吞掉（不编辑字段，也不触发 number 原生步进）。滚轮在 120ms 内合并成一个请求，宿主页面滚动与目标页都收不到该滚轮。
   - **比例语义**：`缩放%` 是**共享显示比例** `view.scale`（Host 权威，0.1–2 即 10–200%，也是"省略 scale 的截图默认密度"），不是 DPR、不是页面 zoom，不改变页面 CSS 视口与布局。手动改比例会取消「适应窗口」并把比例提交给 Host；`view.scale` 变化后 Agent 的默认截图尺寸也随之变化。
   - **「适应窗口」只是本地显示偏好**：勾选时不向 Host 发布任何比例，输入框显示本地计算值（淡色/提示文案说明"仅本地显示"）；取消勾选只回到显示 Host 比例，不发布。收到 Agent 或另一面板的内容变更时采纳 Host 全部值并自动取消本地适应。
   - **窄面板**：尺寸栏与左右分组 `flex-wrap`，空间不足时换行，不覆盖预览区、不出现横向溢出（用户要求）。
   - 宽高范围 200–4096、X/Y 0–10,000,000；非法中间态不提交，Enter/blur 提交、Escape 恢复已接受值。
4. **底部状态栏**（26px）：左 `空闲 / 人类接管 / Agent 操作中` + 分隔线 + `N FPS  M ms`；右侧当前活动文案。FPS/延迟取自宿主页面 rAF，是真实测量值（不是目标页帧率）。
5. **入口**：左侧「更多」下拉里的一行「调试视图」→ 打开中间面板；右侧边栏「开始」页的卡片 → 打开右栏页签。
6. **预览区坐标映射**（行为约定，视觉不变）：帧按 `object-fit: contain` 居中显示，指针/滚轮/拖拽坐标按**实际绘制矩形**（解码后的 naturalWidth/Height + 容器内容盒）换算到页面 CSS 坐标，**不乘宿主 DPR**；letterbox 之外的点击不派发；拖拽在图外结束后仍补发释放，避免按键滞留。画面滚轮按 `W/Pw` 缩放后派发。
7. **没有提示条**：错误通过地址栏红框 + 空状态文案 + 视觉隐藏的 `role="alert"` 表达。

> 第 3 项中的 X/Y 输入框、五个数值框滚轮、fit 本地语义与窄面板 wrap 是**用户明确要求的界面变更**（2026-11-01）；其余样式/文案/图标/间距/颜色/布局仍按冻结约定处理，改动需再次获得用户同意。行为契约见 [viewport-control.md](viewport-control.md) §4–§5，GUI 证据见 [status.md](status.md) 第 9 轮。
