# 已定稿界面规格

> 索引：[docs/index.md](index.md) · **改动需用户同意**（见 [status.md](status.md) 的冻结约定）

1. **顶部环境栏**（44px）：圆角窗口图标 + 单行标题 `Web · 调试视图`（垂直居中，无副标题）+ 右侧运行环境 `select`（9 项，仅 `Web 视图` 可选，其余 `disabled`）。
2. **工具栏**（41px）：后退 / 前进 / 刷新 / 地址栏 / 尺寸调整 / 选择元素（禁用）/ 更多。图标 16×16、`strokeWidth 1.7`、`currentColor`；选择元素用 Chrome「检查元素」样式（虚线框 + 指针）。
3. **尺寸栏**（开启尺寸调整时出现）：左侧预设 `宽屏 1920×1080`、`横屏 1024×768`、`平板 768×1024`、`手机 393×852`（当前档位高亮）；右侧 `宽 × 高 px ☑适应窗口 缩放%` 全部右对齐。
4. **底部状态栏**（26px）：左 `空闲 / 人类接管 / Agent 操作中` + 分隔线 + `N FPS  M ms`；右侧当前活动文案。FPS/延迟取自宿主页面 rAF，是真实测量值（不是目标页帧率）。
5. **入口**：左侧「更多」下拉里的一行「调试视图」→ 打开中间面板；右侧边栏「开始」页的卡片 → 打开右栏页签。
6. **没有提示条**：错误通过地址栏红框 + 空状态文案 + 视觉隐藏的 `role="alert"` 表达。
