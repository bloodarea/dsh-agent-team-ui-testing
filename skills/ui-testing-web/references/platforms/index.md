# 平台索引

本插件**只对 Web 实现了 T1–T4 与网络 P0**；其它平台没有定义、没有实现、不可用。本文件不承诺任何 SDK 已安装，运行时能力以 Agent 当前工具注册表为准。

**宿主 OS**：Web/Chromium 适配器在 Linux、macOS、Windows 三种宿主上都能运行；平台差异（浏览器发现、进程树终止、有头窗口隐藏、目录 fsync）在运行时按 `process.platform` 分支处理，不改变其它平台的行为。上面的"平台"指的是**被测试的目标环境**，与宿主 OS 是两件事。

不要因为面板里存在“运行环境选择器”的置灰项，就假设对应平台已具备 SDK 或工具。新增平台时必须先有真实 Adapter、运行时能力探测与回归证据；不要照搬 Web 的 T1 技术栈去假设其它平台的实现路径。
