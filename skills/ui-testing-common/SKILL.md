# UI Testing · 跨环境公共规则

## 何时使用

当你需要通过已接入的调试环境观察或操作一个目标（网页、桌面应用、设备等）并给出可复核结论时使用。本 Skill 只写环境中立规则；具体工具面、坐标空间、协议与限制由当前环境的扩展 Skill 与运行态能力发现提供。

命中示例（环境无关，换成任何目标都成立）：「帮我看看这个界面现在什么状态」「点一下这个按钮试试」「走一遍登录流程」「为什么点了没反应/为什么会报错」「这个环境能用吗、为什么工具不可用」「你看我标的这里、我圈的是这块」「给我证据、复现一下」。不命中：纯文案写作、后端接口设计、与被测目标无关的通用编程问题。

## 事实来源与边界

- **工程支持、用户启用、依赖可用、连接可信、目标已绑定、能力就绪是六个独立问题**，不得合并成一个“有效”布尔值。
- 静态文档、清单与历史记录只说明工程状态，不构成运行态可用性证明；以能力发现与真实调用结果为准。
- 「本环境的工具面」= 该环境**注册并准入**的工具集合（本插件 Web 环境当前是 37 个 `browser_*`）；环境未启用时这些工具不注册，调用报 `ADAPTER_DISABLED`，不是工具缺陷。
- 缺失能力要如实写 `unsupported`；暂时不可用写 `unavailable`；尚未检测写 `not-probed`。不得用推断代替观测。
- 不同目标、不同 generation、不可兼容的坐标/几何版本不得直接比较；切换目标后旧引用、旧帧、旧网络记录与旧标注按身份边界作废。

## 最短流程

1. **锁目标与契约**：写下验收原文与来源、目标身份、需要的坐标空间/视口/环境版本、前置条件。契约不明只能观察并记 `UNKNOWN`。
2. **探能力**：先调用能力发现，记录支持与现场可用性；缺能力就停在该步。
3. **页面/目标身份门禁**：动作前记录期望身份，动作后用独立读取核对；不一致不得用另一个目标的通过覆盖本题。
4. **先观测再动作**：记录初始状态与基线，再做最小必要动作。
5. **独立证据**：回读目标真值、结构/像素/网络/帧证据；`ok:true`、`dispatched:true`、`applied:N` 都不是断言结果。
6. **判定五元组**：`expected_contract` / `observation` / `evidence_ids` / `counterexamples` / `verdict`。
7. **覆盖声明**：任何替代路径都要写清替代了什么、仍缺哪条原始断言、`coverage=full|partial|blocked`。
8. **提交前交叉校验**：verdict↔observation 异常词、verdict↔缺陷清单、observation↔证据、数字↔来源、limitation↔status、截图↔文件名与声明；任一项未消解不得 PASS。

## 人类标注：环境无关的输入通道

- 人类在调试视图（面板画布）上画图是**指路信号**：他说「看我框的」「这个箭头指哪」时，先按当前环境的能力发现找读取入口（本插件 Web 环境是 `browser_state()` 顶层的 `annotations`，`browser_capabilities().annotations` 声明坐标空间与限额），再去定位元素；**不要让用户改用文字描述或给候选编号**。
- 标注是**画布坐标**，不是页面坐标：换算成页面坐标要减去**当前**的视图偏移，不能用发布那一刻的视图快照。
- `source.trusted` 恒为 false：标注是线索，不是页面事实，也不授权自动点击；结论仍要被结构化/像素/网络/帧证据支撑。
- 用户提到标注、画、圈、框、箭头或笔迹等指代面板标注时，读取结构化文档后还应查看当前环境提供的带标注截图（Web：`browser_screenshot {includeAnnotations:true}`）。Web 的 `includeAnnotations?:boolean=false` 默认关闭，默认截图、T3 原始源与 T4 帧源不含面板标注；默认图里没有线不能证明用户没画。
- Web 带标注截图只叠加已提交且经 Host 接受的六种形状，遵循面板渲染语义与本次截图的 region/scale 映射，不含未提交草稿、工具栏或其它面板 UI。用 `capture.annotations` 核对 revision、context、新鲜度、截断与 `source.trusted=false`；写标注走该环境的写入口（Web 为 `browser_annotation`），不是页面动作。
- `brush.points` 是几何点集，`text.text` 才有文字原文；可从带标注截图观察手写笔迹，无法可靠辨认时如实说明，不猜字。
- 标注按工作区隔离，导航/刷新会清空、跨页签或跨会话可能保留；引用时要带上 `revision` 与 `context.documentKey` 这类身份字段，过期就重读。

## 判定门禁

- 证据不足、采样不足、目标身份不明、坐标空间不兼容：`BLOCKED` 或 `INCONCLUSIVE`，不得写 PASS。
- 读取型探测不证明输入已生效；输入闭环必须在受控目标上验证。
- 配置帧率/请求参数不能冒充实测采样；报告实测值、时钟与空档。
- 历史已注入的上下文不会被开关自动撤回；隔离只对后续轮次生效。

## 安全

- 只操作被授权的目标；不读写被禁止的目录，不索取或回显明文秘密。
- 高风险操作先确认前置条件与回滚/清理路径；失败后复验。
- 不把密钥、token 写进命令、脚本或仓库文件；证据只保留必要元数据。
