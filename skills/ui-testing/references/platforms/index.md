# 平台索引

本插件**只对 Web 实现了 T1 与 T2**；其它平台没有定义、没有实现、不可用。本文件不承诺任何 SDK 已安装，运行时能力以 Agent 当前工具注册表为准。

| 平台 | 文档 | 当前状态 |
|---|---|---|
| Web / Chromium（无头） | `web.md` | T1–T4、网络 P0 与 P0-E 多标签已实现（36 工具，含 `browser_tabs`）；T4 40 条门槛未全覆盖，provider 图像可见性未验证 |
| Windows | 未创建 | 未定义 / 不可用 |
| Linux | 未创建 | 未定义 / 不可用 |
| Android | 未创建 | 未定义 / 不可用 |
| macOS | 未创建 | 未定义 / 不可用 |
| HarmonyOS | 未创建 | 未定义 / 不可用 |
| TUI | 未创建 | 未定义 / 不可用 |
| Game | 未创建 | 未定义 / 不可用 |
| 3D | 未创建 | 未定义 / 不可用 |

不要因为面板里存在“运行环境选择器”的置灰项，就假设对应平台已具备 SDK 或工具。新增平台时必须先有真实 Adapter、运行时能力探测与回归证据；不要照搬 Web 的 T1 技术栈去假设其它平台的实现路径。
