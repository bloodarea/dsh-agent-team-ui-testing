# 灯光、相机、渲染与合成

```json
{"id":"lighting-camera-render","version":"1.0.0","requiredOps":[]}
```

## 输入

阶段 brief、规格相机/灯光片段及 specRef、已绑定对象和已验证相机 ID、参考图与摘要、分辨率/裁切、相机内外参、镜头/传感器映射、引擎、色彩空间/变换、背景和遮罩约定、实际能力版本与资源预算。Agent 观察镜头与作品相机分别记录。

## 操作与边界

先匹配画幅、构图、主要遮挡和明暗层次，再评估材质与细节。缺标定时保留焦距、距离、厚度和光照的替代解释；不能调整几何来掩盖镜头错配。色彩管理与独立照明条件固定后才比较材质。

当前 8 个受控 op 不支持相机内外参创建、灯光、render frame 或 compositor 写入；requiredOps 为空意味着可规划，不证明已执行渲染。`object.transform` 也不能替代未支持的相机配置。经 `blender_view` 的观察视图不等于规范化作品相机。仅当工具能力目录确证可用时读取已有图像/视图或发起支持的采集，缺项逐项阻塞；禁止任意 Python/脚本回退。

渲染/合成配方需记录版本、引擎、输出通道、透明与背景、色彩变换和预算。涉及写入时重做 plan，在 Tools 的 Grant/Lease 下 apply；读图需核对目标、generation 和产物摘要。

## 输出

输出 `version=1.0.0`、briefId/stageId/specRef、boundObjectIds、空执行 proposal.ops、镜头/照明/渲染配方、checks、dependencies 与 blockers。附已有相机与图像的来源、ROI 回映和可重复条件；不伪造缺失的 render artifact。
